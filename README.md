# FST Branch Analyzer 📊

A Python utility for analyzing applicant-to-seat ratios across different FST (Faculté des Sciences et Techniques) cities and academic branches.

## Features

- **Applicant-to-Seat Ratio Calculation**: Computes competitiveness ratios for branches.
- **Rankings**: Automatically sorts and ranks branches by competition intensity.
- **File Export**: Saves evaluation data to `FST.txt`.

## Quick Start

Run `main.py`:
```bash
python main.py
```
